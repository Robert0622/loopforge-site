从一条需求，到可检查的交付

把流程固定下来，
把灵活的部分留给 AI。

同一条 SOP、同样的阶段和检查。实现、评审和测试由不同角色完成；关键节点暂停，等你确认后再推进。

需求定型→方案设计→开发实现→独立评审→测试验证→人工验收→交付汇总

验收不通过，可以打回到指定节点返工。流程可发布版本、复用子 SOP，并按项目配置角色、规则、Skills 和 MCP。

需要 Docker（含 Compose）和 Python 3。安装完成后打开 localhost:8090，创建账号，再通过首页引导跑通第一条 SOP。

git clone https://github.com/Tencent/LoopForge.git
cd LoopForge
bash scripts/install.sh
查看部署指南 ↗

默认面向可信团队，仅监听本机。对公网开放前请阅读账号、权限及 Docker 沙箱的部署边界；预览页不是可执行的公网实例。

平台版与 Local 版

平台版：团队共享可视化 SOP、需求、角色、审批、运行记录和交付证据，支持 Docker 沙箱或自己的执行机器。

Local 版：个人开发者在已有 IDE / CLI 中使用内置交付工作流，不需要服务端。

了解 Local 版 →

Local 不是平台的在线版；平台 SOP 导出到 Local 独立执行尚未实现。
